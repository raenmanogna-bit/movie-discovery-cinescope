### Deploython 2.0

CineScope is a modern movie discovery platform designed to help users explore movies, find films based on their mood, and maintain a personal watchlist.

✨ Features

- 🎬 Movie discovery interface
- 🔎 Movie search
- 🎭 Genre-based filtering
- 🧠 Mood-based movie recommendations
- ⭐ Movie ratings and release information
- ❤️ Personal watchlist
- 💾 Watchlist persistence using LocalStorage
- 📝 Movie details modal
- ▶️ Trailer preview interface
- 🌙 Dark / Light mode
- 📱 Responsive design for desktop and mobile

 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub
- Render

 🎯 Project Objective

CineScope was developed as part of **Deploython 2.0** to create a user-friendly movie discovery experience with search, filtering, mood-based recommendations, and personalized watchlist functionality.
